# 2026-08-25 — Project kickoff

Mad Max VR started today. The game is **Mad Max** (2015, Avalanche Studios,
published by WB Games Interactive), running on Avalanche Studios' proprietary
in-house engine — the same lineage that powers the *Just Cause* series.

This is the "first look" phase: the six-repo standard has just been seeded
(`-mod`, `-dev-archive`, `-modding-notes`, `-staging`, `-engine-research`,
`-external-research`), and no reverse-engineering has started yet. Next step
is engine identification — binary architecture, renderer API, DRM, and an
injection foothold — tracked in
[`mad-max-vr-engine-research`](https://github.com/TefMeister/mad-max-vr-engine-research)'s
`ENGINE-DOSSIER.md`.
